# Timeway Brand v1

This package contains the approved Timeway identity system, finalized on 13 September 2026.

## Start here

- **Brand manual:** `guidelines/Timeway_Brand_Manual_v1.pdf`
- **Quick usage guide:** `guidelines/BRAND_GUIDE.md`
- **Primary website/product logo:** `logos/svg/timeway-primary.svg`
- **Dark-surface logo:** `logos/svg/timeway-reverse.svg`
- **App icon:** `icons/svg/timeway-app-icon.svg`
- **Favicon:** `icons/png/favicon.ico`

## Package structure

| Folder | Contents |
|---|---|
| `logos/` | Primary, reverse, and monochrome horizontal logo variants in SVG and PNG. |
| `icons/` | App icon, favicon, and standalone emblem in SVG, PNG, and ICO. |
| `fonts/DM_Sans/` | Approved font files plus the SIL Open Font License 1.1 text. |
| `guidelines/` | Final brand manual PDF and Markdown quick guide. |
| `proof/` | Approved-logo proof board. |
| `source/` | Master vector artwork for the emblem. |

## Approved essentials

| Item | Specification |
|---|---|
| Primary message | Find a time that works. |
| Primary colour | Timeway Ink — `#16395E` |
| Accent colour | Timeway Seafoam — `#79BBAE` |
| Neutral surface | Timeway Paper — `#F8F8F4` |
| Typeface | DM Sans — Regular 400, Medium 500, SemiBold 600 |

All logo SVGs contain outlined wordmark artwork and do not require the font to display correctly. Refer to the final brand manual before applying the assets.
